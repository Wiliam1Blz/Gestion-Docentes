# CERTUS · Gestión Docente

Aplicación web responsiva para gestionar el **legajo docente**: datos personales, evaluaciones por semestre, encuestas, supervisión de clases,
capacitaciones, reportes descargables y **constancias verificables**.

 //implementar una plataforma web que centralice la gestión docente con acceso según el rol de cada usuario.


 Estructura 

| Incluye |
|---|
| Legajo docente |
| Evaluaciones, encuestas y supervisión de clases | 
| Capacitaciones con cupos, inscripción, asistencia y nota | 
| Constancias en PDF con verificación pública | 
| Reportes en Excel, CSV y PDF |
| Roles, control de acceso y auditoría |
